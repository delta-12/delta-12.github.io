Homework Tracker

Homework Tracker is a website that allows a user to track their upcoming homework assignments. Users can add their courses, then create assignments for each course with a due date and time. They can view a list of all upcoming assignments on their Dashboard or view assignments course by course. Users can mark assignments complete, which will then be hidden after the due date has passed. Assignments that remain incomplete after the due date has passed remain visible and are highlighted to indicate they are overdue.

This project was built with React, Bootswatch, MongoDB, and Nodejs. View this project on Github!
